    How I analyse data
    
      
    Every project answers a business question with a repeatable process. If a number appears on this page, you can
        trace it back to a dataset and a repo.
    
      
    
        
    
          
    1. Question
    
          
    Define the decision the data should support.
    
        
    
        
    
          
    2. Source
    
          
    Name the dataset, its origin and its limits.
    
        
    
        
    
          
    3. Clean
    
          
    Handle nulls, duplicates and outliers; log each fix.
    
        
    
        
    
          
    4. Analyse
    
          
    SQL and Python to test the question, not just describe data.
    
        
    
        
    
          
    5. Insight
    
          
    State the finding in one plain sentence with a number.
    
        
    
        
    
          
    6. Action
    
          
    Recommend what the business should do next.

          What is synced, and how to set it up
          
      Synced: tasks, projects, learning progress, readiness and formula practice. Published projects are visible
            to every visitor. Everything else is private to you.
      
          
      Setup takes about 10 minutes: create a Google Sheet, add Code.gs from the backend
            folder through Extensions > Apps Script, run setup(), set OWNER_EMAIL and CLIENT_ID as Script properties,
            deploy as a Web app (access: Anyone), then paste the Web app URL and your OAuth client ID into
            CONFIG.backend. backend/SETUP.md lists every step.
